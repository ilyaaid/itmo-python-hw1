# Руководство

## Локальный просмотр

Установите зависимости и запустите сервер разработки:

```bash
python -m pip install -r requirements.txt
python -m mkdocs serve
```

MkDocs покажет локальный адрес в терминале. Изменения в файлах `docs/` появятся в браузере после обновления страницы.

## Сборка

Чтобы получить готовый статический сайт, выполните:

```bash
python -m mkdocs build --strict
```

Результат находится в папке `site/`. Строгий режим помогает заметить ошибки в настройках и ссылках до публикации.

## Изменение оформления

Название сайта, меню и тема задаются в `mkdocs.yml`. В верхней панели опубликованного сайта можно переключать светлое и тёмное оформление.
