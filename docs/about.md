# О проекте

Сайт собран с помощью MkDocs. Исходные страницы находятся в папке `docs/`, а порядок разделов задаётся в `mkdocs.yml`. После сборки готовые HTML-файлы появляются в папке `site/`.

## Как устроена публикация

При пуше в `main` GitHub Actions собирает документацию, публикует её в GitHub Pages, а затем копирует на Рег.ру. Для других веток создаются отдельные preview-поддомены. Это позволяет посмотреть изменения до их объединения с основной веткой.

Обе опубликованные страницы проходят проверку HTTP-ответа и контрольного текста. Для основного сайта также сохраняется предыдущая версия файлов, которую можно вернуть вручную.
